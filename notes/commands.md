# 🚀 React + Vite Commands Cheat Sheet

---

## 📁 Project Setup (Folders)

## Create main projects folder
mkdir -p ~/Projects

## Go into Projects folder
cd ~/Projects

## Create new React project folder
mkdir 24hr-story-feature

## Go into project folder
cd 24hr-story-feature



-----------------------------------------------



## ⚡ Vite Setup Command

## Create Vite project
npm create vite@latest project-name

⚠️ Note:
If during setup you select:

Install with npm and start now?
● Yes

then:
✔ npm install
✔ npm run dev

automatically run ho jate hain (manually karne ki zaroorat nahi hoti)


## 📦 Manual Dependency Commands

## Install dependencies
npm install

---

## ▶️ Run Project

## Start development server
npm run dev

---

## 🛑 Stop Server

Ctrl + C

-------------------------------------------------
